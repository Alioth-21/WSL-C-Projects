# 1. 项目介绍

1. 项目2：日程计划

2. 核心主题：
    - 动态内存分配（malloc/free）
    - 单向链表
    - 链式栈

3. 功能定义：
    - 使用**链表**存储待办事项（每个事项包含ID号和内容content）。
        
    - 支持添加、删除、查找、修改。
        
    - **进阶要求**：实现一个“撤销（Undo）”功能。**这里用到栈**——每次修改前把当前链表头指针压入“历史栈”，撤销时从栈顶弹回。
        
    - **攻克目标**：亲手画内存图，追踪`malloc`和`free`的每一个动作，确保**全程无内存泄漏**（可用Valgrind检测）。
