# 要求

1. C-3 简易端口扫描器（网络与并发期）

2. **核心主题**：Socket编程、TCP协议、多线程/多进程

3. **功能定义**：
    
    - 命令行输入 `./scanner 192.168.1.1 20-100`，扫描该IP的20到100端口。
        
    - 采用**多线程**（或`fork`多进程）实现并发，**必须**将扫描时间从串行的几分钟压缩到几秒内。
        
    - 输出开放的端口列表及对应服务（如80-HTTP，22-SSH）。
        
4. **攻克目标**：理解`阻塞与非阻塞`、`connect超时设置`，以及**线程间共享数据时的互斥锁（Mutex）**。
